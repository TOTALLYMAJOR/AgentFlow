# AgentFlow documentation

This directory is installed with AgentFlow so architecture, operating rules,
installation guidance, and repository templates remain available offline.

- `architecture/` contains the supplied product specification.
- `implementation/` contains the complete supplied Codex milestone prompt.
- `INSTALLATION.md` documents global and user-service installation.
- `TROUBLESHOOTING.md` records verified recovery steps.
- `SECURITY.md` defines the local trust boundary.
- `ASSUMPTIONS.md` resolves protocol gaps in the source specification.

Release packages also include checksummed SQL migration files under
`dist/migrations/`, the built dashboard under `dist/web/`, and repository
templates under `examples/`.
